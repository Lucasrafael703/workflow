{% comment %} Região do Kanban de Demandas: o componente ÚNICO do sistema (templates/kanban/*, o mesmo de Quadros), usado pela tela de sempre (boards/demand_work_board.html) e pelo Workspace (workspace/demandas.html). Aqui só ficam os dados que o adaptador (static/js/demand-kanban.js) precisa: data-move-url endereço de gravação do agrupamento, com `/itens/0/valor/` no lugar do id (o adaptador troca o 0 pelo id do cartão) data-rename-url o mesmo, para o título (renomear no lugar) data-group-by agrupamento efetivo (pede confirmação ao mover por setor) data-inline-url / -sentinel / data-people-url / data-options-url os mesmos endereços da edição inline da Lista: os campos do cartão (Responsável, Prazo, Setor, Etapa, Status, Prioridade) editam com activity-inline-edit.js As raias vêm de `kanban` (boards/demand_kanban.py); `?fragmento=raias` devolve só `kanban/_lanes.html` para redesenhar. Quem pode configurar o quadro recebe também `kanban_config` (JSON): os dados do diálogo "Configurar cartões" (o mesmo de Quadros). {% endcomment %}
